# Lottie

Import `LottiePlayer` from `slides:animation/LottiePlayer` and supply your own
parsed JSON `source`. The host must include native Lottie. Duration, looping,
preview progress and view style are configurable. Native progress uses the shared
slide clock, so previews stay fixed and outgoing/paused content retains its pose.
No animation JSON or demo scene is bundled by this entrypoint.
